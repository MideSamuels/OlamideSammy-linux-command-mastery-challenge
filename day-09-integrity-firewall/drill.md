# Day 9 Drill: Integrity, Encryption & Firewalling

## Objective

Practice verifying file integrity, protecting a file with immutable attributes, and configuring basic firewall rules.

## Steps Completed

1. Created a practice file and generated its SHA-256 checksum using sha256sum.
2. Made the practice file immutable using chattr +i.
3. Confirmed the file attribute using lsattr.
4. Checked the UFW firewall status using ufw status.
5. Allowed SSH (port 22) and HTTPS (port 443) using UFW.
