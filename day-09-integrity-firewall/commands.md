Day 9 Drill: Integrity, Encryption & Firewalling

| **Command** | **Purpose** |
|---|---|
| `md5sum` | Generate an MD5 checksum for a file |
| `sha256sum` | Generate a SHA-256 checksum for a file |
| `gpg --gen-key` | Generate a GPG key pair |
| `gpg --encrypt` | Encrypt a file using GPG |
| `gpg --decrypt` | Decrypt a GPG-encrypted file |
| `chattr +i` | Make a file immutable |
| `lsattr` | Display file attributes |
| `ufw enable` | Enable the UFW firewall |
| `ufw allow` | Allow specified firewall ports or services |
| `ufw status` | Display the current firewall status |
