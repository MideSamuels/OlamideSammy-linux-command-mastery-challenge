# Day 22 — process-signals

10 Commands

These are the exact 10 commands and process-control operations for Day 22.

| #  | Command / Operation | Purpose                                                          |
| -- | ------------------- | ---------------------------------------------------------------- |
| 1  | `kill`              | Send a signal to a process using its PID                         |
| 2  | `kill -9`           | Forcefully terminate a process using the SIGKILL signal          |
| 3  | `kill -HUP`         | Send the SIGHUP signal to a process                              |
| 4  | `killall`           | Send a signal to processes matching a specified name             |
| 5  | `pkill`             | Find and signal processes based on their name or other criteria  |
| 6  | `fg`                | Bring a background or suspended job to the foreground            |
| 7  | `bg`                | Resume a suspended job in the background                         |
| 8  | `Ctrl+Z (suspend)`  | Suspend the currently running foreground process                 |
| 9  | `nohup`             | Run a command so it can continue after the terminal session ends |
| 10 | `disown`            | Remove a job from the shell's job table                          |
