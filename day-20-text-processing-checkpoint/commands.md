# Day 20 — Text Processing & Pipes

10 Commands

These are the exact 10 commands and pipe operations for Day 20, in the order specified by your Linux Command Mastery Challenge.

| #  | Command / Operation | Purpose                                                    |                                                         |
| -- | ------------------- | ---------------------------------------------------------- | ------------------------------------------------------- |
| 1  | `grep`              | Search for specific text or patterns in a file             |                                                         |
| 2  | `grep -r`           | Search for specific text recursively through directories   |                                                         |
| 3  | `grep -i`           | Search for text without considering uppercase or lowercase |                                                         |
| 4  | `sort`              | Sort lines of text alphabetically                          |                                                         |
| 5  | `sort -n`           | Sort lines containing numbers in numerical order           |                                                         |
| 6  | `uniq`              | Remove consecutive duplicate lines from sorted input       |                                                         |
| 7  | `cut -d',' -f`      | Extract specific fields from comma-separated data          |                                                         |
| 8  | `awk '{print $1}'`  | Extract and print the first field from each line           |                                                         |
| 9  | `sed 's/old/new/g'` | Replace every occurrence of one word with another          |                                                         |
| 10 | `                   | `                                                          | Connect multiple commands together to create a pipeline |
