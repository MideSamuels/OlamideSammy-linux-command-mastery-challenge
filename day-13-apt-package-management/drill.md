# Day 13 Drill: Package Management

## Objective

Practice managing software packages on Ubuntu by updating package information, searching for a package, inspecting package details, installing and removing a package, and cleaning up unused package files.

## Steps Completed

1. Updated the local package index using apt update.
2. Upgraded installed packages using apt upgrade.
3. Searched for a package using apt search.
4. Inspected package information using apt show.
5. Installed a test package using apt install.
6. Listed installed packages using apt list --installed.
7. Removed the test package using apt remove.
8. Practiced removing unused dependencies using apt autoremove.
9. Removed downloaded package files from the local cache using apt clean.
10. Practiced removing a package and its configuration files using apt purge.
