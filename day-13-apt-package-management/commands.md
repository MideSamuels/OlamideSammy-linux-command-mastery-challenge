# Day 13: Package Management

| **Command**            | **Purpose**                                          |
| ---------------------- | ---------------------------------------------------- |
| `apt update`           | Update the local package index                       |
| `apt upgrade`          | Upgrade installed packages                           |
| `apt install`          | Install a package                                    |
| `apt remove`           | Remove an installed package                          |
| `apt purge`            | Remove a package and its configuration files         |
| `apt search`           | Search for available packages                        |
| `apt show`             | Display detailed information about a package         |
| `apt list --installed` | List installed packages                              |
| `apt autoremove`       | Remove unused dependency packages                    |
| `apt clean`            | Remove downloaded package files from the local cache |
