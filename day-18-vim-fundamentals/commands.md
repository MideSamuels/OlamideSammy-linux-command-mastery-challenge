# Day 18 — Vim Fundamentals 

#10 Commands


| #  | Command / Operation | Purpose                                         |
| -- | ------------------- | ----------------------------------------------- |
| 1  | `vim <file>`        | Open or create a file using the Vim text editor |
| 2  | `i`                 | Enter insert mode to type or edit text          |
| 3  | `Esc`               | Exit insert mode and return to normal mode      |
| 4  | `:w`                | Save the current file                           |
| 5  | `:q`                | Quit Vim                                        |
| 6  | `:wq / :x`          | Save changes and quit Vim                       |
| 7  | `:q!`               | Quit Vim without saving changes                 |
| 8  | `dd`                | Delete the current line                         |
| 9  | `yy / p`            | Copy the current line and paste it              |
| 10 | `u / Ctrl+r`        | Undo and redo changes                           |
