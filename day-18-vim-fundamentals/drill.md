# Day 18 Drill: Vim Fundamentals

## Objective

Create a new file in Vim, add three lines of text, save it, reopen it, delete the middle line, undo the deletion, and save and quit.

## Steps Completed

1. Opened a new file using `"vim day18-practice.txt"`.
2. Entered insert mode using `"i"`.
3. Added three lines of text to the file.
4. Exited insert mode using `"Esc"`.
5. Saved the file using `":w"`.
6. Quit Vim using `":q"`.
7. Reopened the file using `"vim day18-practice.txt"`.
8. Navigated to the middle line.
9. Deleted the middle line using `"dd"`.
10. Undid the deletion using `"u"`.
11. Copied a line using `"yy"`.
12. Pasted the copied line using `"p"`.
13. Redid a change using `"Ctrl+r"`.
14. Saved and exited using `":wq"`.
