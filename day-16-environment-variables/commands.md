# Day 16 - Environment Variables

10 Commands

These are the exact 10 commands for Day 16, in the order specified by your Linux Command Mastery Challenge.

| #  | Command                | Purpose                                                                        |
| -- | ---------------------- | ------------------------------------------------------------------------------ |
| 1  | `printenv`             | Display all environment variables available in the current shell               |
| 2  | `printenv HOME`        | Display the value of the HOME environment variable                             |
| 3  | `echo $VAR`            | Display the value stored in an environment variable                            |
| 4  | `export`               | Display exported environment variables or export a variable to child processes |
| 5  | `unset`                | Remove an environment variable from the current shell                          |
| 6  | `env`                  | Display the environment variables available to the current command environment |
| 7  | `source`               | Read and apply commands from a file in the current shell session               |
| 8  | `echo $PATH`           | Display the directories listed in the current PATH variable                    |
| 9  | `export PATH=$PATH:`   | Modify and export the PATH variable for the current shell session              |
| 10 | `cat /etc/environment` | Display system-wide environment variable configuration                         |
