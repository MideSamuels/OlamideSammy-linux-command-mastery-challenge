## What I practiced

I practiced working with Linux environment variables, including viewing existing variables, creating temporary variables, removing variables, reloading shell configuration, and managing the system PATH.

## What stood out to me

What stood out to me was understanding how environment variables provide configuration information to the shell and applications. I also learned how the PATH variable determines where the shell searches for executable commands and how changes to it can be applied temporarily to the current session.
