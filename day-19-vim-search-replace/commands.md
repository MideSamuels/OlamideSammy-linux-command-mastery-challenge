# Day 19 — Vim Navigation & Search/Replace

10 Commands

These are the exact 10 commands and Vim operations for Day 19, in the order specified by your Linux Command Mastery Challenge.

| #  | Command / Operation | Purpose                                                                 |
| -- | ------------------- | ----------------------------------------------------------------------- |
| 1  | `gg / G`            | Move to the beginning or end of the file                                |
| 2  | `:10`               | Jump directly to line 10                                                |
| 3  | `/`                 | Search forward for text                                                 |
| 4  | `?`                 | Search backward for text                                                |
| 5  | `n / N`             | Move between search matches                                             |
| 6  | `:%s/old/new/g`     | Replace every occurrence of one word with another across the whole file |
| 7  | `dw`                | Delete from the cursor position through the current word                |
| 8  | `x`                 | Delete the character under the cursor                                   |
| 9  | `o / O`             | Open a new line below or above the current line                         |
| 10 | `ZZ`                | Save and quit Vim                                                       |
