# Day 19 Drill: Vim Navigation & Search/Replace

## Objective

In a 50-line config file, jump straight to line 10, search for a keyword, jump between all matches, then replace every occurrence of one word with another across the whole file.

## Steps Completed

1. Created and opened a 50-line configuration file using Vim.
2. Used `gg` to move to the beginning of the file.
3. Used `G` to move to the end of the file.
4. Used `:10` to jump directly to line 10.
5. Used `/` to search forward for a keyword.
6. Used `?` to search backward for a keyword.
7. Used `n` and `N` to move between search matches.
8. Used `:%s/old/new/g` to replace every occurrence of one word with another across the whole file.
9. Used `dw` to delete a word.
10. Used `x` to delete a character.
11. Used `o` and `O` to open new lines below and above the current line.
12. Used `ZZ` to save and quit Vim.
