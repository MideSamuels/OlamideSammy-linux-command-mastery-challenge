## Command Summary

| Command | Purpose |
|---|---|
| `find -name` | Find by name |
| `find -type` | Find by type |
| `find -size` | Find by size |
| `find -mtime` | Find by modification time |
| `find -perm` | Find by permission |
| `locate` | Search the locate database |
| `updatedb` | Update the locate database |
| `du` | Show disk usage |
| `du -sh` | Show summarized disk usage |
| `df -h` | Show filesystem space |
