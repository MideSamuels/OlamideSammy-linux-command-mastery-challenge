## What I practiced

I practiced searching the Linux filesystem using different search conditions and checking disk usage. I worked with filename, file type, file size, modification time, and permission-based searches, while also learning how `locate` and `updatedb` work together.

I also practiced using `du`, `du -sh`, and `df -h` to understand how much storage directories are using and how much space remains available on a filesystem.

## What surprised me

I learned that different filesystem search commands allow me to narrow down results based on specific conditions such as filename, size, modification time, and permissions. I also found the difference between `du` and `df` useful because `du` shows space used by files and directories, while `df` shows available and used space on filesystems.
