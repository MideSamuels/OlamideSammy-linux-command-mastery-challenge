# Day 23 — Init Systems & systemctl Basics 

10 Commands

These are the exact 10 commands and systemctl operations for Day 23.

| #  | Command / Operation      | Purpose                                                    |
| -- | ------------------------ | ---------------------------------------------------------- |
| 1  | `systemctl start`        | Start a system service                                     |
| 2  | `systemctl stop`         | Stop a system service                                      |
| 3  | `systemctl restart`      | Restart a system service                                   |
| 4  | `systemctl reload`       | Reload a service's configuration without fully stopping it |
| 5  | `systemctl enable`       | Configure a service to start automatically at boot         |
| 6  | `systemctl disable`      | Prevent a service from starting automatically at boot      |
| 7  | `systemctl enable --now` | Enable a service at boot and start it immediately          |
| 8  | `systemctl status`       | Display the current status of a service                    |
| 9  | `systemctl is-active`    | Check whether a service is currently active                |
| 10 | `systemctl is-enabled`   | Check whether a service is enabled to start at boot        |
