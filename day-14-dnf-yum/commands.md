# Day 14: DNF/YUM & Alternative Installs

| **Command**          | **Purpose**                             |
| -------------------- | --------------------------------------- |
| `dnf update`         | Update packages on DNF-based systems    |
| `dnf install`        | Install a package using DNF             |
| `dnf remove`         | Remove an installed package using DNF   |
| `dnf search`         | Search for available packages using DNF |
| `yum install`        | Install a package using YUM             |
| `rpm -qa`            | List all installed RPM packages         |
| `snap install`       | Install an application using Snap       |
| `add-apt-repository` | Add a software repository to APT        |
| `dpkg -i`            | Install a local `.deb` package          |
| `pip / npm install`  | Install Python or Node.js packages      |
