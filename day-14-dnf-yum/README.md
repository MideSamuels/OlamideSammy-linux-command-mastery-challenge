## What I practiced

I practiced using Linux package management and software installation commands, including DNF, YUM, RPM, Snap, APT repositories, DPKG, pip, and npm across different Linux environments.

## What stood out to me

I learned that different Linux distributions use different package management systems. While Ubuntu commonly uses APT and DPKG, systems such as Amazon Linux and RHEL use DNF, YUM, and RPM. I also learned about alternative installation methods such as Snap, pip, and npm.
