# Day 14 Drill: DNF/YUM & Alternative Installs

## Objective

Practice package management on an Amazon Linux or RHEL system by updating packages, installing and removing software, searching for packages, checking installed RPM packages, and comparing the workflow with the equivalent APT steps from Day 13.

## Steps Completed

1. Updated package information using `dnf update`.
2. Installed a test package using `dnf install`.
3. Removed the test package using `dnf remove`.
4. Searched for a package using `dnf search`.
5. Practiced installing a package using `yum install`.
6. Confirmed installed RPM packages using `rpm -qa`.
7. Practiced installing an application using `snap install`.
8. Practiced adding a software repository using `add-apt-repository`.
9. Practiced installing a Debian package using `dpkg -i`.
10. Practiced installing packages using `pip / npm install`.
