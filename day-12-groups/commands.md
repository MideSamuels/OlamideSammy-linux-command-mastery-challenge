# Day 12: Groups & Access Circles

| **Command**      | **Purpose**                                   |
| ---------------- | --------------------------------------------- |
| `groupadd`       | Create a new group                            |
| `groupdel`       | Delete an existing group                      |
| `gpasswd -a`     | Add a user to a group                         |
| `gpasswd -d`     | Remove a user from a group                    |
| `getent group`   | Display information about groups              |
| `getent passwd`  | Display information about user accounts       |
| `groups`         | Show the groups a user belongs to             |
| `id -Gn`         | Display the group names for a user            |
| `newgrp`         | Change the current shell's effective group    |
| `cat /etc/group` | Display the contents of the system group file |
