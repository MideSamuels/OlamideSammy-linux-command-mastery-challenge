# Day 21 — Viewing Processes

10 Commands

These are the 10 commands and process operations for Day 21.

| #  | Command / Operation | Purpose                                                            |
| -- | ------------------- | ------------------------------------------------------------------ |
| 1  | `ps aux`            | Display detailed information about running processes for all users |
| 2  | `ps -ef`            | Display a full-format list of running processes                    |
| 3  | `ps -u`             | Display processes associated with a specified user                 |
| 4  | `top`               | View running processes and system activity in real time            |
| 5  | `htop`              | Interactively view and manage running processes                    |
| 6  | `pgrep`             | Find the PID of a process by its name                              |
| 7  | `pstree`            | Display running processes in a parent-child tree structure         |
| 8  | `lsof -i`           | Identify processes using network connections and ports             |
| 9  | `jobs`              | Display jobs running in the current shell                          |
| 10 | `nice / renice`     | Start or change the priority of a running process                  |
