# Day 10 Drill: Security Checkpoint & Audit

## Objective

Produce a mini security audit of the Ubuntu system by reviewing login activity, current users, inactive accounts, and sudo activity.

## Steps Completed

1. Checked recent login activity using last.
2. Checked currently logged-in users using w and who.
3. Reviewed user login information using lastlog.
4. Checked user accounts and password information using passwd and chage -l.
5. Checked failed login attempts using lastb.
6. Reviewed sudo commands from the current shell history using history | grep sudo.
