Day 08 Commands: Privilege Escalation & Identity

| **Command** | **Purpose** |
|---|---|
| `sudo` | Run a command with administrator privileges |
| `sudo -i` | Open an interactive root shell |
| `sudo -u` | Run a command as another user |
| `sudo !!` | Re-run the previous command with `sudo` |
| `sudo -l` | List the commands your account is allowed to run with `sudo` |
| `visudo` | Safely edit the sudoers configuration |
| `su` | Switch to another user account |
| `su -` | Switch to another user with their login environment |
| `whoami` | Display the current username |
| `id` | Display the current user ID, group ID, and group memberships |
