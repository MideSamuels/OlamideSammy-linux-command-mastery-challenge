Day 8 Drill: Privilege Escalation & Identity

Objective

Practice using sudo to run commands with elevated privileges, rerun a failed command, and check the commands permitted for my account.

Steps Completed

Attempted a command without sudo that required elevated privileges.
Re-ran the previous command using sudo !!.
Used sudo -l to view the commands my account is permitted to run.
Used whoami to confirm my current username.
Used id to view my user and group information.
