## Commands covered today

The commands covered today are:

cat: Displays the contents of a file.
less: Allows you to read a file one screen at a time.
head: Displays the beginning of a file.
head -n: Displays a specified number of lines from the beginning of a file.
tail: Displays the end of a file.
tail -f: Continuously monitors the end of a file for new content.
wc: Counts lines, words, and bytes in a file.
wc -l: Counts the number of lines in a file.
file: Identifies the type of a file.
stat: Displays detailed metadata about a file.
