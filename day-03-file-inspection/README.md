# Day 03: Reading & Inspecting Files

**Phase 1 - File Navigation & Filesystem Mastery | Day 3 of 30**

## Commands covered today

See 'commands.md' for all 10 commands with syntax and my own explanation of what each one does and when I would reach for it.

## What I practiced

I practiced reading and inspecting a log file on my Ubuntu system. For the drill, I viewed the log file with 'cat', paged through it with `less`, displayed the first and last 15 lines, counted the number of lines, identified the file type, and inspected the file's metadata using `stat`.

## What surprised me

I learned that different commands provide different levels of information about a file. While `cat` and `less` allow me to inspect the file's contents, `file` identifies the file type and `stat` provides detailed information about the file itself, including its metadata.
