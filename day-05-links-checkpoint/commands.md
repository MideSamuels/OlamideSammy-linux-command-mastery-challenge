| **Command**    | **Purpose**                                       |
| -------------- | ------------------------------------------------- |
| `tree`         | Display files and directories in a tree structure |
| `tree -L`      | Limit the depth of the tree display               |
| `ln`           | Create a hard link                                |
| `ln -s`        | Create a symbolic (soft) link                     |
| `readlink`     | Display the target of a symbolic link             |
| `realpath`     | Display the absolute path of a file or directory  |
| `basename`     | Extract the filename from a path                  |
| `dirname`      | Extract the directory portion of a path           |
| `pushd / popd` | Navigate directories using the directory stack    |
| `ls -lt`       | List files by modification time, newest first     |
