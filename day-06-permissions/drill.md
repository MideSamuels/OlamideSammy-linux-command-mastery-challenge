Day 6 Drill: Reading & Setting Permissions

Objective

Practice reading and changing file permissions using ls -l and chmod.

Steps Completed

Created a script file.
Set it to rwxr-xr-x using the relative chmod method.
Set it using the assignment method.
Set it using octal chmod 755.
Confirmed each change with ls -l.

Permission Methods
Relative: Add or remove permissions.
Assignment: Set permissions directly.
Octal: Use numeric permissions such as 755.
