# LINUX-COMMAND-MASTERY-CHALLENGE
30-Day Linux Command Mastery Challenge : Hands-on practice, documentation, and evidence of Linux command-line skills.

Welcome to my 30-Day Linux Command Mastery Challenge, where I am building practical Linux command-line proficiency 
by learning and executing 300 Linux commands across 30 days. Each day focuses on a specific Linux skill, supported by hands-on drills,
command explanations, terminal evidence, and a personal command journal. This repository demonstrates my ability to work confidently 
with the Linux command line, navigate and manage files, troubleshoot systems, automate tasks, and apply Linux skills to real-world 
Cloud and DevOps environments.

Hi, I'm Olamide Samuel, an engineering graduate with an interest in Cloud Engineering, DevOps, Linux, and modern infrastructure technologies.

I am currently strengthening my practical Linux and Cloud/DevOps skills through hands-on projects and structured challenges like this one.

Through this challenge, I am developing the ability to:

Navigate and manage Linux systems from the command line
Work with files, directories, permissions, users, and processes
Troubleshoot Linux systems and networking issues
Automate repetitive tasks with shell scripting
Manage services and system resources
Work with Git and GitHub from Linux
Apply Linux knowledge to Cloud and DevOps environments
Build stronger command-line problem-solving skills
