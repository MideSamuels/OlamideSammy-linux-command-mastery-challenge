# 30-Day Linux Command Mastery Challenge

**Hands-on practice, documentation, and evidence of Linux command-line skills.**

## About the Challenge

Welcome to my 30-Day Linux Command Mastery Challenge, where I am building practical Linux command-line skills by learning and executing 300 Linux commands across 30 days.

Each day focuses on a specific Linux skill through hands-on practice, command explanations, terminal evidence, and practical drills.

This repository documents my progress as I develop the ability to navigate Linux systems, manage files and permissions, troubleshoot issues, automate tasks, and apply Linux skills in **Cloud Engineering and DevOps environments**.

## About Me

Hi, I'm **Olamide Samuel**, an engineering graduate with an interest in Cloud Engineering, DevOps, Linux, and modern infrastructure technologies.

I am strengthening my practical Linux and Cloud/DevOps skills through hands-on projects and structured challenges like this one.

## Skills I'm Developing

Through this challenge, I am developing my ability to:

- Navigate and manage Linux systems
- Work with files, directories, permissions, users, and processes
- Troubleshoot Linux systems and networking issues
- Automate tasks using shell scripting
- Manage services and system resources
- Work with Git and GitHub from Linux
- Apply Linux knowledge to Cloud and DevOps environments
