What I practiced

I practiced creating nested directories, creating empty files, copying files and directories, moving and renaming files, and safely removing files and empty directories. For the drill, I created the nested `practice/2026/april` directory, created three empty files inside it, copied the `practice` directory to a `backup` location, renamed one file, and safely removed the empty directories using `rmdir`.

What surprised me

I initially expected `rmdir` to remove a directory regardless of its contents. Instead, I learned that `rmdir` only removes empty directories. This helped me understand why files must be removed first before the directories containing them can be safely deleted.
