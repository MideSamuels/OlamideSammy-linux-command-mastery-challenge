# Day 11: Creating & Managing Users

| **Command**     | **Purpose**                                                       |
| --------------- | ----------------------------------------------------------------- |
| `useradd`       | Create a new user account                                         |
| `useradd -m`    | Create a new user with a home directory                           |
| `useradd -m -s` | Create a new user with a home directory and specified login shell |
| `adduser`       | Create a user through an interactive process                      |
| `passwd`        | Set or change a user's password                                   |
| `usermod -aG`   | Add a user to a supplementary group                               |
| `usermod -s`    | Change a user's login shell                                       |
| `usermod -l`    | Change a user's login name                                        |
| `userdel`       | Delete a user account                                             |
| `userdel -r`    | Delete a user account and its home directory                      |
