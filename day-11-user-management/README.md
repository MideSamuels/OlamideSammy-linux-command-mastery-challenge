# Day 11: Creating & Managing Users

**Phase 3 - Users, Groups & Package Management | Day 11 of 30**

Refer to [commands.md](./commands.md) for the 10 commands practiced today, including their syntax and my own explanation of what each command does and when I would use it.

## What I practiced

I practiced using Linux commands to create and manage user accounts, create home directories, configure login shells, set passwords, add users to secondary groups, rename user accounts, and remove users from the system.

## What stood out to me

I learned how Linux provides different commands for managing the complete lifecycle of a user account, from creating and configuring a user to modifying and eventually removing the account.
