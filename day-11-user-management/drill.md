# Day 11 Drill: Creating & Managing Users

## Objective

Create and manage a test Linux user account by creating the user with a home directory and Bash shell, setting a password, adding the user to a secondary group, renaming the account, and removing the user along with the home directory.

## Steps Completed

1. Created a new user with a home directory and Bash shell using useradd -m -s.
2. Set the user's password using passwd.
3. Added the user to a secondary group using usermod -aG.
4. Renamed the user account using usermod -l.
5. Removed the user account and home directory using userdel -r.
