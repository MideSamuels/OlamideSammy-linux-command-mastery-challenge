## What I practiced

I practiced working with Linux shell configuration, including editing the `.bashrc` file, reloading shell configuration, checking shell configuration files, creating and removing aliases, and identifying commands using `type`, `which`, and `whereis`.

## What stood out to me

What stood out to me was understanding how shell configuration can be customized and persisted through files such as `.bashrc`. I also learned how `source` can reload configuration changes without opening a new terminal and how aliases can make frequently used commands easier to access.
