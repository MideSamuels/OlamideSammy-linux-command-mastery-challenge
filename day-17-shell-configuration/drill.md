# Day 17 Drill: Persisting Configuration

## Objective

Add a permanent environment variable and custom alias to `.bashrc`, reload the configuration, and confirm both persist in a fresh session.

## Steps Completed

1. Opened `.bashrc` using `"nano ~/.bashrc"`.
2. Added a permanent environment variable and custom alias.
3. Saved the changes and reloaded `.bashrc` using `"source ~/.bashrc"`.
4. Confirmed the alias using `"alias"`.
5. Tested alias removal using `"unalias"`.
6. Checked commands using `"type"`.
7. Located commands using `"which"` and `"whereis"`.
8. Checked `.bash_profile` using `"cat ~/.bash_profile"`.
9. Reviewed `/etc/environment`.
10. Reviewed `/etc/bash.bashrc`.
11. Opened a fresh terminal session.
12. Confirmed that the environment variable and alias persisted.
