# Day 17: Persisting Configuration

10 Commands

These are the exact 10 commands for Day 17, in the order specified by your Linux Command Mastery Challenge.

| #  | Command                      | Purpose                                                                    |
| -- | ---------------------------- | -------------------------------------------------------------------------- |
| 1  | `nano ~/.bashrc`             | Open the user's Bash configuration file for editing                        |
| 2  | `source ~/.bashrc`           | Reload the Bash configuration in the current shell                         |
| 3  | `cat ~/.bash_profile`        | Display the contents of the user's Bash profile                            |
| 4  | `sudo nano /etc/environment` | Open the system-wide environment configuration file for editing            |
| 5  | `sudo nano /etc/bash.bashrc` | Open the system-wide Bash configuration file for editing                   |
| 6  | `alias`                      | Display the aliases currently defined in the shell                         |
| 7  | `unalias`                    | Remove a defined shell alias                                               |
| 8  | `type`                       | Identify how a command is interpreted by the shell                         |
| 9  | `which`                      | Show the path of an executable command                                     |
| 10 | `whereis`                    | Locate the binary, source, and manual page files associated with a command |
