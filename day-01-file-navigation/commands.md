pwd: Displays the full path of my current working directory.
ls: Lists the files and directories in my current location.
ls -l: Lists directory contents in long format with details such as permissions, ownership, size, and modification time.
ls -a: Lists all files and directories, including hidden files.
ls -la: Lists all files, including hidden files, in long format with detailed information.
ls -lh: Lists files in long format with human-readable file sizes such as KB, MB, and GB.
cd (absolute path): Changes my current directory to the specified absolute path.
cd ..: Moves me one level up to the parent directory.
cd ~: Takes me directly to my home directory.
cd -: Switches me back to my previous working directory.
