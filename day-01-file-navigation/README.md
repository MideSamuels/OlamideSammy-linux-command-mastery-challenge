What I practiced
I practiced checking my current working directory, listing files and directories, viewing hidden files, and navigating between directories using absolute paths and shortcuts such as '..', '~', and '-'. For the drill, I navigated to '/var/log', returned to my home directory, and then used 'cd -' to return to '/var/log' before listing its contents with 'ls -lh'.

What surprised me
I initially expected 'cd -' to return me to '/var/log', but after using 'cd ..', it returned me to '/var'. This helped me understand that 'cd -' switches to the immediate previous working directory.
